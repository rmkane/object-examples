# Lua

This is a simple Lua project that demonstrates the use of modules and object-oriented programming.

## Files

- `main.lua`: The main entry point of the application.
- `utils.lua`: A module containing utility functions.
- `employee.lua`: A module containing the `Employee` class and related methods.

## Running the Project

To run the project, execute the following command in your terminal:

```sh
make
```
